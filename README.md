# 🎬 Filmx — Frontend Client (Test UI)

> **Note:** This user interface was generated with **Google AI Studio** solely to visually test and demonstrate the [Filmx Spring Boot Backend](https://github.com/coZaer/filmx).

## 🚀 Quick Start

1. **Start the Backend:** Make sure the [Filmx Backend](https://github.com/coZaer/filmx) is running on `http://localhost:8080`.
2. **Install dependencies:**
   ```bash
   npm install --legacy-peer-deps
   ```
3. **Run the UI:**
   ```bash
   npm run dev
   ```
4. Open `http://localhost:3000` in your browser.
